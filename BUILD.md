# Инструкция по сборке Photo to Word

Этот документ описывает процесс сборки автономного `.exe` для Windows
из исходного кода проекта.

---

## 📋 Требования

- **Python 3.10+** ([скачать](https://www.python.org/downloads/))
- **pip** (идёт в комплекте с Python)
- **Windows 10/11** (сборка для macOS/Linux возможна, но не тестировалась)
- ~500 МБ свободного места на диске

Проверьте версию Python:

```bash
python --version
# Должно вывести: Python 3.10.x или выше
```

---

## 🔧 Шаг 1. Клонирование и подготовка окружения

```bash
git clone https://github.com/USERNAME/photo-to-word.git
cd photo-to-word
```

Создайте виртуальное окружение (рекомендуется):

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate # macOS / Linux
```

---

## 📦 Шаг 2. Установка зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
pip install pyinstaller
```

Проверьте, что всё установилось:

```bash
python -c "import PySide6, docx, PIL; print('OK')"
```

Если вывело `OK` — всё готово к сборке.

---

## ✅ Шаг 3. Проверка перед сборкой

Убедитесь, что в корне проекта лежат обязательные файлы:

```
photoword.py       ← основной скрипт
photoword.spec     ← конфигурация PyInstaller
icon.ico           ← иконка приложения
logo.png           ← логотип для окна «О программе»
qr.png             ← QR-код CloudTips
```

Если какого-то файла нет — приложение либо не запустится, либо
будет работать без соответствующего ресурса (без иконки, без QR-кода).

Запустите программу напрямую, чтобы убедиться, что она работает:

```bash
python photoword.py
```

Если окно открылось и функции работают — переходите к сборке.

---

## 🏗️ Шаг 4. Сборка `.exe`

В корне проекта выполните:

```bash
pyinstaller photoword.spec
```

Процесс занимает **30 секунд – 2 минуты**. В конце вы увидите:

```
...
Building EXE from EXE-00.toc completed successfully.
```

После этого в проекте появятся две папки:

- **`build/`** — временные файлы (можно удалить).
- **`dist/`** — готовый результат.

Внутри `dist/` находится файл:

```
dist/PhotoToWord.exe
```

Это и есть финальное приложение.

---

## 🧪 Шаг 5. Проверка `.exe`

1. **Перенесите `PhotoToWord.exe`** в отдельную папку (например, на рабочий стол).
2. **Запустите** двойным кликом.
3. **Проверьте**:
   - Открывается ли окно без консоли.
   - Отображается ли иконка в панели задач.
   - Работает ли кнопка «О программе» и показывает ли QR-код.
   - Создаётся ли Word-документ.
4. **Проверьте** программу на чистой системе или у коллеги — если
   она запускается без установленного Python, значит сборка удалась.

Размер готового `.exe` — **100–200 МБ** (это нормально: PySide6
включает в себя библиотеки Qt).

## 🚀 Шаг 6. Публикация релиза на GitHub

1. Перейдите в раздел **Releases** вашего репозитория.
2. Нажмите **Draft a new release**.
3. Укажите **Tag**: `v2.2.1` (совпадает с версией в коде).
4. **Title**: `Photo to Word 2.2.1`.
5. **Description**: кратко опишите изменения.
6. **Прикрепите** `PhotoToWord.exe` в раздел «Attach binaries».
7. Нажмите **Publish release**.

Пользователи смогут скачать `.exe` по ссылке:

```
https://github.com/USERNAME/photo-to-word/releases/latest
```

## 🛠️ Возможные проблемы

### «Windows Defender блокирует файл»

**Причина**: PyInstaller-сборки часто ложно срабатывают в антивирусах.
**Решение**: подпишите `.exe` сертификатом (платно) или попросите
пользователей добавить программу в исключения. Официальный
ответ Microsoft: [документация](https://learn.microsoft.com/).

### «Не найдена иконка / логотип / QR-код»

**Причина**: файлы не были указаны в `.spec` или отсутствуют.
**Решение**: проверьте секцию `datas` в `photoword.spec`:

```python
datas=[
    ('icon.ico', '.'),
    ('logo.png', '.'),
    ('qr.png', '.'),
],
```

### «ModuleNotFoundError: No module named 'xxx'»

**Причина**: какой-то модуль не был автоматически найден PyInstaller.
**Решение**: добавьте его в `hiddenimports` в `.spec`:

```python
hiddenimports=[
    'PIL._tkinter_finder',
    'docx',
    'some_missing_module',
],
```

И пересоберите:
```bash
pyinstaller photoword.spec --clean
```

### «Сборка завершилась, но .exe не запускается»

**Решение**:
1. Запустите `.exe` из командной строки, чтобы увидеть ошибку:
   ```bash
   dist\PhotoToWord.exe
   ```
2. Проверьте, что все зависимости установлены в **том же** окружении,
   из которого запускался PyInstaller.
3. Убедитесь, что `.spec` актуален.

### «Размер .exe больше 250 МБ»

**Причина**: PyInstaller включил лишние модули Qt.
**Решение**: добавьте в `.spec` секцию `excludes`:

```python
excludes=[
    'PySide6.QtWebEngineCore',
    'PySide6.QtWebEngineWidgets',
    'PySide6.Qt3DCore',
    'PySide6.QtCharts',
    'PySide6.QtMultimedia',
    'PySide6.QtQuick',
    'PySide6.QtQml',
],
```

Это может уменьшить размер на 30–60 МБ.
